# Implementation Plan: production-hardening

## Overview

Seven independently shippable phases in the design's merge order (A→G, plus R10 docs). Backend is C# / .NET 8 in `SchemeReady/backend/`; frontend is JavaScript + React 19 in `SchemeReady/frontend/`.

**Phase B must complete before Phase E.** `tests/baseline/MatchingBaseline.json` frozen in B is the oracle that proves E's rule externalisation changed no behaviour.

**Sandbox limitation:** tasks marked **[dev machine]** cannot be verified here — no .NET SDK, no NuGet, no Docker/Testcontainers, no PostgreSQL, no npm install. Write the code in the sandbox; run the verification locally per `docs/local-build-and-migrations.md`.
